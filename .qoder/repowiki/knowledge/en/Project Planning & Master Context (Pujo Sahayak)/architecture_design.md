Two complementary artifacts under `tasks/` plus a top-level master context document. `Pujo_Sahayak_Master_Project_Context.md` is the single source of truth for product philosophy, user journey (Discover → Explore → Understand → Plan → Visit → Share → Meet), feature spec per section (Home, Favorites, Planner, Maya, Meets, Safety, etc.), and explicit constraints (e.g. Maya name, demo-data honesty, no fake integrations). `tasks/plan.md` translates that into an implementation plan: React 18 + TypeScript + Vite + Tailwind v4 + React Router v6 + Zustand + Framer Motion + Leaflet, with a fixed Screen→Route table mapping all 21 mockup screens to URLs, a six-phase task breakdown, verification criteria, risks, and open questions. `tasks/todo.md` is the actionable checklist (T1–T18) with dependencies, scope tags (S/M/L), and per-task verify steps; each task is intended to leave the app in a runnable state so sessions can resume. Dependency direction is one-way: code must conform to the context doc's rules and the plan's route map; the plan references the context doc by section number (e.g. §50, §52, §42, §58) as the authoritative requirement.
